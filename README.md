# 👥 Customer Segmentation — RFM & K-Means

## 📌 Project Overview
Segmentation of 96,095 customers from Olist 
e-commerce dataset using RFM analysis 
and K-Means clustering algorithm.

## 🎯 Business Objectives
- Identify distinct customer behavioral groups
- Support targeted marketing strategies
- Detect inactive vs premium customers

## 🛠️ Tools & Libraries
- Python | Pandas | Scikit-learn
- Matplotlib | Seaborn

## 📊 Methodology
1. RFM Feature Engineering
2. Data Normalization (StandardScaler)
3. Elbow Method (optimal clusters)
4. K-Means Clustering (k=4)
5. Business interpretation

## 🔍 Key Insights
- 👥 Total customers : 96,095
- 🆕 Recent Customers : 50,506 (52%)
- 😴 Inactive Customers : 37,587 (39%)
- 🥇 Premium Customers : 2,482 (2.5%)
- 💛 Loyal Customers : 5,520 (5.7%)
- 💰 Premium avg value : 1,197 BRL
- ⚠️ 39% inactive → big reactivation opportunity

## 📁 Dataset
[Brazilian E-Commerce Dataset by Olist]
(https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
